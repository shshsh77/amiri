# AMIRI VAPE

Локальный сайт на Node.js 24+. Сервер и бот сохраняют пользователей, запросы на вход и сеансы в SQLite. Мобильная навигация собирается из React, TypeScript и Tailwind CSS 4.

## Запуск

В PowerShell из папки проекта:

```powershell
npm.cmd ci
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
npm.cmd start
```

Откройте [магазин](http://localhost:3031/) или [админ-панель](http://localhost:3031/admin). При `TELEGRAM_MODE=off` можно открыть локальную витрину, чтобы проверить интерфейс. Для доступа к каталогу, админке и заказам подключите Telegram. Используйте адрес из `PUBLIC_ORIGIN`. Для внешнего адреса укажите HTTPS и настройте TLS на обратном прокси.

## Подключение Telegram

В `.env` укажите имя своего бота в `TELEGRAM_BOT_USERNAME`, а числовые ID администраторов через запятую в `ADMIN_TELEGRAM_IDS`. Свой ID можно посмотреть командой `/id` после запуска бота. Перезапустите сервер после изменения настроек.

- Для бота без подключённого обработчика установите `TELEGRAM_MODE=poll` и заполните `TELEGRAM_BOT_TOKEN`. Один процесс получает обновления Telegram.
- Если бот уже работает, установите `TELEGRAM_MODE=embedded`. Подключите `createRegistrationHandler` из `bot.js` к действующему обработчику обновлений. Передайте хранилище `openAuthStore`, открытое с тем же абсолютным путём к SQLite, что и у сайта, имя бота, адрес сайта и функцию вызова методов Telegram. SQLite по умолчанию находится в `data/amiri.sqlite`. Можно указать абсолютный путь через `DB_PATH`.

Пример подключения в Node.js к существующему обработчику обновлений:

```js
import { openAuthStore } from "./auth-store.js";
import { createRegistrationHandler, createTelegramClient } from "./bot.js";

const handleRegistration = createRegistrationHandler({
  store: openAuthStore(process.env.DB_PATH),
  callTelegram: createTelegramClient(process.env.TELEGRAM_BOT_TOKEN),
  publicOrigin: process.env.PUBLIC_ORIGIN,
  username: process.env.TELEGRAM_BOT_USERNAME.replace(/^@/, ""),
});

async function onUpdate(update) {
  if (update.message?.text === "/start") {
    return handleExistingUpdate(update);
  }
  if (await handleRegistration(update)) return;
  return handleExistingUpdate(update);
}
```

Вызывайте `onUpdate` с теми же обновлениями, которые бот уже получает. `handleExistingUpdate` в примере обозначает ваше текущее поведение. Для входа боту нужны обновления `message` и `callback_query`.

Первое подтверждение «Да, это я» создаёт профиль. Команда `/register` позволяет зарегистрироваться прямо в чате.

## Админ-панель и заказы

Владелец из `ADMIN_TELEGRAM_IDS` назначает редакторов в разделе «Пользователи», блокирует и разблокирует аккаунты. Блокировка завершает открытые сеансы.

Владелец и редакторы управляют ассортиментом через разделы «Категории» и «Позиции». В «Категориях» можно создать раздел, переименовать его и добавить баннер. В «Позициях» задаются название, категория, бренд, линейка, цена, остаток и видимость товара. Чтобы показать несколько вкусов или вариантов на одном экране, укажите у них одинаковые категорию, бренд и линейку. У каждого варианта остаются свои цена и остаток.

Для фотографии или баннера положите PNG в папку `img` и укажите путь вида `/img/product.png`. Для фотографий товаров используйте прозрачный фон. Используйте латинские буквы, цифры, дефисы или подчёркивания в имени файла. Пропорции баннера категории — 1200 × 640. Заголовок и число линеек добавляются поверх изображения. В поле «Бейдж» можно отметить новинку или повторное поступление.

Оформленный заказ виден клиенту и сотрудникам. Сотрудник может корректировать количество до сборки, менять статус заказа и указывать трек-номер при отправке. Отмена до отправки возвращает остатки. Оплата и отправка уведомлений не подключены.

В подборку «Топ за 30 дней» попадают позиции из завершённых за этот период заказов. Рейтинг сортируется по количеству проданных единиц.

## Mini App в Telegram

Укажите публичный HTTPS-адрес без пути в `MINI_APP_ORIGIN`. HTTPS-прокси должен передавать запросы на этот Node.js сервер с исходным заголовком `Host`. Обычный сайт продолжает использовать `PUBLIC_ORIGIN`.

После запуска сервера выполните `npm.cmd run telegram:menu`. Скрипт проверит доступ к `/mini` и настроит кнопку «Открыть магазин» в меню бота. Если внешняя интеграция управляет общим меню, можно настроить кнопку в одном чате командой `npm.cmd run telegram:menu -- --chat-id 123456789`, подставив Telegram ID пользователя. В режиме `poll` бот также отправляет кнопку в ответ на `/start`.

При смене HTTPS-адреса обновите `MINI_APP_ORIGIN`, перезапустите сервер и настройте меню заново. В режиме `embedded` передайте публичный URL с путём `/mini` как `miniAppUrl` при создании обработчика.

## Мобильная навигация

В `components/ui` лежат `glass-tab-bar.tsx` для мобильной панели и `glassmorphism-navigation.tsx` для компьютерной. Адаптер магазина находится в `components/store-navigation.tsx`. Стили Tailwind находятся в `styles/index.css`. Путь `@/components/ui` задан в `components.json`, чтобы shadcn CLI устанавливал UI-компоненты туда, где их ожидают импорты. Добавлять другие компоненты можно через `npx.cmd shadcn@latest add <component>`.

`npm.cmd run build:navigation` проверяет TypeScript и собирает JS и CSS в `dist`. При `npm.cmd start` сборка запускается автоматически.

## Передача проекта следующему GPT

Работай из папки `amiri`. Соседний `w1` — предыдущая версия магазина со своим сервером и своей базой. Для тестирования AMIRI используется бот [@w1_Markert_bot](https://t.me/w1_Markert_bot). Запускай только один процесс бота в режиме `poll`.

- Старая кнопка «Открыть магазин» ведёт на [Mini App](https://sheffpc.tailb2a066.ts.net/mini). Tailscale Funnel на тестовом ПК направляет запросы на `127.0.0.1:3031`. При ошибке 502 проверь, запущен ли AMIRI и указывает ли Funnel на 3031. Пути `/mini` и `/mini-app` обслуживает `server.js`, вход из Telegram обрабатывает `mini-app.js`.
- Админка и витрина читают позиции из таблицы `products` в SQLite через `shop-store.js`. Витрина показывает позиции с включённым флажком «Показывать в каталоге». При пустой цене карточка видна с пометкой «Цена уточняется», а добавить её в заказ можно после сохранения цены. Для магазина правь `app.js` и `style.css`, для форм админки — `admin.html` и `admin-shop.js`.
- В локальной базе на момент передачи 19 тестовых позиций по 67 ₽ с остатком 99 штук на каждую. Фото привязаны к прозрачным PNG в `img`. Реальные цены и остатки меняются через «Админ → Позиции».
- В Git входят код, изображения и зашифрованная копия рабочих файлов `transfer/amiri-runtime.enc`. В ней полные `.env` и SQLite на момент переноса, включая каталог, аккаунты и заказы.

Чтобы восстановить рабочие файлы, возьми `amiri-transfer.key` у владельца и выполни команду в свежем клоне перед запуском. Храни ключ отдельно от репозитория.

```powershell
node scripts/restore-transfer.mjs 'D:/snusik/amiri-transfer.key'
```

Если Mini App запускается на другом ПК, проверь `MINI_APP_ORIGIN` и настрой прокси до смены адреса в боте.
